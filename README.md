# cs-350
CS-350 Emerging Systems Architecture and Technologies Portfolio

Summarize the project and what problem it was solving.
The main project in this course was creating a smart thermostat prototype for SysTec. The goal was to build a system that could read temperature data, allow users to change temperature settings, and switch between heating, cooling, and off states. This project helped demonstrate how software can interact directly with hardware components to solve a real-world problem.

My two selected artifacts are the Module Four LED Display and Potentiometer Lab and the Final Smart Thermostat Project. The display lab helped me learn how to connect and configure hardware components, while the thermostat project brought together everything we learned throughout the course into a working embedded system.

What did you do particularly well?

I think I did well integrate the hardware and software components together. I was able to get the buttons, temperature sensor, LEDs, and display working as part of one system. I also did a good job troubleshooting problems as they came up and testing my code to make sure the thermostat behaved correctly in each state despite many challenges in the process I understood it better each time

Where could you improve?

One area where I could improve is making my code more efficient and modular. While the project worked as expected, I could spend more time organizing functions and reducing repetitive code. I would also like to learn more about adding networking features because that would make the thermostat closer to a real smart home device.

What tools and/or resources are you adding to your support network?

Throughout this course, I used the course lab guides, Code Composer Studio documentation, TI resources, and online programming references. These resources helped me troubleshoot hardware issues and better understand embedded systems concepts. I plan to continue using these tools in future courses and projects.

What skills from this project will be particularly transferable to other projects and/or course work?

The skills I gained from this project will be useful in future computer science courses and technical projects. Some of the most valuable skills include debugging, problem-solving, hardware and software integration, state machine design, GPIO programming, interrupt handling, and working with sensors. These skills can be applied to both embedded systems and software development projects.

How did you make this project maintainable, readable, and adaptable?

I focused on keeping my code organized and easy to follow by using meaningful variable names, comments where needed, and separating functionality into logical sections. The state machine structure made the thermostat easier to understand and modify. This approach would make it easier for someone else, or even myself later on, to update and expand the project.
